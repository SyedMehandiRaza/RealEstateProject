# Requirements

## Confirmed requirements

- [REQ-001] Stack: Node.js + Express backend, React frontend, MySQL with Sequelize.
- [REQ-002] Every input field is validated with Zod on both frontend and backend. Acceptance: the same invalid input produces the identical error message in the UI (client-side) and in the API response, proven by schema, API and e2e parity tests.
- [REQ-003] Unit and integration tests use Jest; end-to-end tests use Playwright.
- [REQ-004] The UI reproduces the Figma designs exactly, organized as pages per module. Acceptance: each page passes a screenshot comparison against its Figma frame.
