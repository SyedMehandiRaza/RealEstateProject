## Design questions

- No mobile frames; no loading, error, or empty states; no validation error states on any form.
- The four Verify frames are identical; the password-reset Verify still says "Verify Your Account" and is not visibly different.
- The Verify text uses a sample address that looks like a real person's email; replace with a placeholder before using it in tests.
- Forgot Password copy says "email address or phone number" but the only field is "Email"; change it to "email address" (DEC-022).
- Log in label "Email/ Phone number" must become "Email": phone is a contact field only (DEC-022).
- Profile Photo accepts "PDF, JPG, PNG" (PDF for a photo looks like a copy-paste).
- The Reject screen lists only the rejected document; the Pending/Approved screens list two documents even for the developer flow (no company certificate shown).
- Dropdown frame names ("WEB Select Type", "WEB Select role") do not match the field labels; mapping is by canvas position.
