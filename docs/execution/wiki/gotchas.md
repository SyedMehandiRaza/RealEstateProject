# Gotchas

- 2026-10-28: Jest runs ESM through babel-jest, so `import.meta` fails in tests; use `process.cwd()` (Jest cwd is the workspace folder).
- 2026-10-28: files inside `__tests__/` are picked up as test suites; shared fakes live in `backend/src/test/`.
- 2026-10-28: `npm run format` runs `prettier --write .`; use `npx prettier --check .` for checking.
- 2026-10-28: Python is not installed; large bash heredocs can fail to parse, so write scratch `.cjs` scripts and run them with node.
- 2026-10-29: never read `backend/.env` (project deny rule). A `git grep --no-index` over the working tree reads it anyway; scan only staged files with `git grep --cached`.
- 2026-10-29 (TASK-017): name DB-backed tests `*.int.test.js`; plain `npx jest` runs them in parallel and they fail on purpose ("must run serially"). Use `npm test -w backend` or `npm run test:integration -w backend`.
- 2026-10-29 (TASK-017): the auto-mode classifier blocks `sequelize-cli db:migrate:undo:all`, even on `real_estate_test`. The migration round trip test is opt-in (`TEST_MIGRATION_ROUNDTRIP=true`) for the user to run.
- 2026-10-29 (TASK-017): the fake queue repository makes new rows due at epoch 0, but MySQL makes them due at insert time (wall clock). An integration test whose clock is behind real time will not see freshly queued files as due.
- 2026-10-29 (TASK-017): DATETIME columns have no fractional seconds and MySQL rounds them, so compare stored times in whole seconds.
- 2026-10-29 (TASK-018): nodemon from a dev server that is already running restarts on every save under `backend/src`, so a probe of `/api/health` can hit that server instead of yours. Check who owns port 5000 (`Get-NetTCPConnection -LocalPort 5000`) before stopping anything, and never kill processes you did not start.
- 2026-10-29 (TASK-018): the default `smtpMailer` throws under `NODE_ENV=test`. A test that sends mail must use `createTestApp()` or inject a fake mailer.
- 2026-10-29 (TASK-019): Sequelize already drops the fraction of a `DATE` (no precision) when writing DATETIME, so a boundary test that starts mid-second cannot catch a `>` vs `>=` slip. Run expiry boundaries from a whole-second clock too (`clock.set(...)`).
- 2026-10-29 (TASK-019): validation answers before any query, so parity tests are unit tests (`*Validation.test.js`) that need no MySQL. Keep one case per `it.each` row: the per-IP limiter (20 per 15 min) is reset only between tests.
- 2026-10-29 (TASK-019): `npm run check` runs `prettier --check .`, which also scans untracked files such as `.playwright-mcp/*.yml` browser snapshots; check your own files with `npx prettier --check "!.playwright-mcp/**" .` and report the rest.
- 2026-10-29 (TASK-019): the integration DB briefly refused the `real_estate` login while the user moved MySQL from 3307 to 3306; it worked again minutes later. An "Access denied" from global setup is environment, not code: report it and do not read `backend/.env`.
- 2026-10-29 (TASK-031): checkouts have CRLF (`core.autocrlf=true`) and Prettier writes LF, so `npx prettier --write <folder>` marks every file in it as modified. Pass only the files you changed, or `git checkout --` the line-ending-only ones (`git diff --ignore-cr-at-eol --stat` shows the real changes).
- 2026-10-29 (TASK-031): the Figma auth file has no variables (`get_variable_defs` returns `{}`); tokens are the raw values named by role in `frontend/src/styles/tokens.css`. The generated Tailwind for the selected tab gradient (`from-[66.896%]`) does not match the render; sampling the PNG showed an even 0-100% fade.
- 2026-10-29 (TASK-031): CSS Modules (`*.module.css`) work in Vite and in Jest (identity-obj-proxy). React 19 passes `ref` as a normal prop, so `{...register(name)}` works on function components without forwardRef.
- 2026-10-29 (TASK-032): the Playwright MCP saves screenshots only under the main checkout (`Real_Estate/` or its `.playwright-mcp/`), not the scratchpad or a worktree path. To screenshot components without a route, a temporary `frontend/preview/index.html` served by `npx vite --port <free port>` works; delete it before committing.
- 2026-10-29 (TASK-032): `npm ci` in a fresh worktree failed once with EINTEGRITY on a registry tarball; a plain retry succeeded.
- 2026-10-29 (coordinator): the user edits files in parallel (e.g. the MySQL port move to 3306 in README, env.example, STATUS.md, environment.md). Never commit their hunks: stage only your own lines by writing the staged blob (`git show :<file>` + edit, `git hash-object -w`, `git update-index --cacheinfo`).
- 2026-10-29 (coordinator): worktree agents commit on `worktree-agent-*` branches; the coordinator cherry-picks onto `feature/auth`, resolving wiki conflicts by keeping both sides. Stack dependent frontend worktrees with `git reset --hard <prior commit>`.
- 2026-10-29 (TASK-034): to screenshot a page that reads React Router location state (Verify email), set it in the browser with `history.replaceState({ usr: { email: "name@example.com" }, key: "qa", idx: 0 }, "", "/verify-email")` and reload. The Playwright MCP browser is shared between parallel agents: its first page may be another agent's, so navigate to your own port and close only your page.
- 2026-10-29 (coordinator): while a backend agent runs integration tests, do not run backend tests in parallel (one shared `real_estate_test`); the coordinator checks shared/frontend/lint/prettier/build after a frontend merge and relies on the backend agent's full check.
- 2026-10-29 (TASK-020): `verificationCodes.issue` now enforces the 60 s cooldown and 5-per-hour cap, including the sign-up code. A test that issues another code for the same purpose must first `clock.advance(60 * 1000)`, or it gets `ResendRefusedError` (429).
- 2026-10-29 (TASK-033): `baseQueryWithReauth` tries POST `/auth/refresh` after every 401, including a failed `/auth/login`. MSW runs with `onUnhandledRequest: 'error'`, so an RTL test that answers 401 must also mock `/auth/refresh` (answer 401).
- 2026-10-29 (TASK-021): every login runs a real bcrypt compare (cost 12, about 0.3 s), so a test with 10+ logins needs a longer timeout (`jest.setTimeout`) and trips the per-IP limiter (20 per 15 min, sign-up and verify included); call `resetRateLimiters()` mid-test when the per-IP limit is not what the test checks. To count queries, `jest.spyOn(sequelize, 'query')` sees every SQL statement.
- 2026-10-29 (TASK-036): fixed the TASK-033 trap: `baseQueryWithReauth` no longer refreshes after a 401 from the public SPEC-001 auth routes (`PUBLIC_AUTH_PATHS` in `baseApi.js`), so RTL tests of login / sign-up / verify / password pages need no `/auth/refresh` mock. A new public auth route must be added to that set.
- 2026-10-29 (TASK-022): a refresh token that was rotated or logged out counts as reuse at POST `/refresh` and revokes every session of the Account. A test that reuses a cookie after `refresh` or `logOut` (test/authFlows.js) kills its other sessions too; take the new cookie with `refreshTokenOf(res)`. cookie-parser turns a `j:` cookie into an object, so never hash a cookie value without a string check.
- 2026-10-29 (TASK-035): to screenshot a ProtectedRoute page without a backend, the temporary `frontend/preview/` harness can render `routes` with `makeStore({ auth: { accessToken, user } })` and `createMemoryRouter` (path and router state from the query string). In user-event, the first Tab on an auth page lands on "Go back"/"Back to home", not the form.
- 2026-10-29 (TASK-035): frontend RTL suites can hit the 5 s Jest timeout when many parallel agents load the machine (SignUpPage, VerifyEmailPage); they pass alone and on re-run. Re-run before treating it as a real failure; raise `testTimeout` only if it recurs on a quiet machine.
- 2026-10-29 (TASK-023): in `backend/`, `npx jest --selectProjects unit <file>` ran every unit suite; filter with `--testPathPatterns <regex>`. Under a full parallel unit run `utils/__tests__/password.test.js` (bcrypt cost 12) can hit the 5 s timeout; it passes alone.
- 2026-10-29 (TASK-023): a test reads a reset token with `createResetTokens({ parentSecret: env.JWT_ACCESS_SECRET, clock })` from `modules/auth/resetToken.js` (keys are HKDF-derived, so `jwt.verify` with the access secret refuses it). Forgot and resend share the `password_reset` cooldown, so a test that asks twice must `clock.advance(60 * 1000)` in between.
- 2026-10-29 (TASK-024): `obtainResetToken(app, mailer, email)` and `resetPassword(app, { resetToken, password })` in `test/authFlows.js` drive the reset flow. A reset revokes every refresh token of the Account, so refreshing an earlier cookie afterwards is a reuse (401, harmless). Each reset runs one bcrypt hash (cost 12), so suites with several resets need `jest.setTimeout`. A refused reset token is 401 with `resetToken.required` as `error.message`; only a missing token is a 422 field error.
- 2026-10-29 (TASK-039): under `jest-fixed-jsdom`, `FormData` is Node's but the global `File` is jsdom's, so `formData.append(name, file)` throws "Expected value to be an instance of Blob". Build test files with `import { File } from 'node:buffer'`; MSW's `request.formData()` then returns them with name, type and size. userEvent's `upload` honours `accept`, so use `userEvent.setup({ applyAccept: false })` to test a wrong type.
- 2026-10-29 (TASK-040): AuthSplitLayout always renders its `h1`, so a loading state with `title=""` gives an empty heading that `findByRole('heading', { level: 1 })` finds first; wait for the heading by name. Content that must sit above the heading (the status icon tile) can be a child with CSS `order: -1` inside the layout's flex column, keeping its gap.
- 2026-10-29 (TASK-025): signed-in routes run `authenticate` and `authorize` before `validate`, so their parity tests need a Bearer token. `signAccessToken({ userId: 1, roles: ['buyer'] })` works without a database: validation answers before the service loads the Account. `selectCountry(app, token, code)` in `test/authFlows.js` drives PUT `/me/country`.
- 2026-10-29 (TASK-047): replaces the TASK-040 `order: -1` note: content above an auth heading goes in AuthSplitLayout's `icon` prop (first child of the content column, same `contentGap`). Status tile tints and sizes are tokens (`--color-status-*-bg`, `--size-status-tile`/`-glyph`).
- 2026-10-29 (TASK-046): jsdom has no `navigator.locks`, so `baseQueryWithReauth` takes its no-lock path in RTL tests. To test the lock, define a fake with `Object.defineProperty(navigator, 'locks', { value, configurable: true })` and `delete navigator.locks` after; simulate a second tab with `jest.isolateModules` (a fresh baseApi module has its own in-tab refresh).
- 2026-10-29 (TASK-026): POST `/me/roles/developer` does not return a token. A test that needs a Developer token after it must take the cookie from sign-up/verify (`refreshTokenOf(res)`) and call `refresh(app, cookie)`; the old access token still says `['buyer']`. `becomeDeveloper(app, token)` is in `test/authFlows.js`.
