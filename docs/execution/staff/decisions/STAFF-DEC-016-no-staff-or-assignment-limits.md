# STAFF-DEC-016: No limit on staff or property assignments in this build

- **Status:** accepted (user, 2026-10-31)
- **Answers:** STAFF-Q-020
- **Tickets:** set by /to-tickets

## Decision

- A developer can add any number of staff members, and a staff member can be assigned any number of the employer's properties.
- A future Subscription module may add plan limits; it would add its own check and error then.

## Why

No limit is designed or known.

## Alternatives rejected

- A fixed cap: no number was given.
